# Passkeys verständlich erklärt – ohne Hype

Ein Passkey ist ein Anmeldeverfahren auf Grundlage der Public-Key-Kryptografie. Statt ein gemeinsames Geheimnis auf einer Website einzugeben, verwendet Ihr Gerät oder Passwortmanager einen privaten Schlüssel, um eine Anfrage des Dienstes zu beantworten. Der Dienst speichert den dazugehörigen öffentlichen Schlüssel, aus dem sich der private Schlüssel nicht wiederherstellen lässt.

Für die angemeldete Person sieht der Vorgang oft so aus, dass sie eine Anfrage mit Geräte-PIN, Fingerabdruck oder Gesichtserkennung bestätigt. Eine biometrische Prüfung findet, falls sie eingesetzt wird, auf dem Gerät statt; sie wird nicht als Passkey an die Website übermittelt.

## Was ist anders als bei einem Passwort?

Bei einem Passwort erstellen Sie ein Geheimnis und geben es bei der Anmeldung an einen Dienst weiter. Das führt zu bekannten Problemen: Menschen verwenden Passwörter mehrfach, geben sie auf überzeugend gefälschten Seiten ein oder wissen nicht mehr, wo sie sie gespeichert haben.

Ein Passkey ist an den Dienst gebunden, für den er erstellt wurde. Bei einer standardbasierten Anmeldung prüft der Browser, ob die Anmeldeinformation zu der Website gehört, die die Authentifizierung anfordert. Dadurch wird es deutlich schwieriger, einen Passkey versehentlich auf einer nachgemachten Website zu verwenden. Die [Übersicht der FIDO Alliance zu Passkeys](https://fidoalliance.org/passkeys/) und der [Web-Authentication-Standard](https://www.w3.org/TR/webauthn-3/) beschreiben das zugrunde liegende Verfahren.

## Wo Ihr Passkey gespeichert ist

Manche Passkeys sind an ein einzelnes Gerät gebunden. Andere werden von der gewählten Plattform oder dem Passwortmanager zwischen Geräten synchronisiert. Das kann die Kontowiederherstellung und einen Gerätewechsel erleichtern. Dadurch werden aber auch Ihr Anbieterkonto und dessen Wiederherstellungsoptionen wichtig.

Bevor Sie ein Passwort ersetzen, prüfen Sie, welcher Anbieter den Passkey speichert, wie Sie sich auf einem anderen Gerät anmelden und welche Wiederherstellungsmöglichkeiten der Dienst bietet. Wenn mehrere Passkeys oder Sicherheitsschlüssel unterstützt werden, kann eine zweite kompatible Methode das Risiko verringern, dass Sie durch ein verlorenes Gerät ausgesperrt werden.

## Eine Checkliste für eine ruhige Einrichtung

1. Beginnen Sie mit einem wichtigen Konto, das Passkeys ausdrücklich unterstützt, zum Beispiel einem Konto, das Sie bereits mit Mehr-Faktor-Authentifizierung schützen.
2. Lesen Sie die Wiederherstellungsanleitung des Dienstes, bevor Sie die Anmeldemethode ändern.
3. Prüfen Sie, wo der Passkey gespeichert wird und ob er auf Ihren anderen Geräten verfügbar ist.
4. Behalten Sie eine Wiederherstellungsoption, auf die Sie tatsächlich zugreifen können, und bewahren Sie Ersatzcodes sicher auf.
5. Testen Sie die Anmeldung auf einem anderen Gerät oder in einem anderen Browser, bevor Sie die Passwort-Alternative entfernen.

Bezeichnungen und Abfragen unterscheiden sich je nach Dienst. Wenn eine Website Sie auffordert, einen QR-Code zu scannen oder eine Anmeldung zu bestätigen, vergewissern Sie sich, dass Sie den Vorgang beim echten Dienst gestartet haben und wissen, welches Gerät Sie autorisieren.

## Kein Grund, auf alle anderen Schutzmaßnahmen zu verzichten

Passkeys verringern einige Risiken im Zusammenhang mit Passwörtern, beseitigen aber nicht alle Kontoprobleme. Ein kompromittiertes Gerät, ein schwacher Wiederherstellungsprozess oder ein Social-Engineering-Versuch können weiterhin eine Rolle spielen. Schützen Sie Ihre Geräte und Wiederherstellungswege und prüfen Sie die Sicherheitsoptionen der einzelnen Dienste.

Sie müssen nicht alle Konten auf einmal umstellen. Probieren Sie es mit einem Konto aus, stellen Sie sicher, dass Sie es wiederherstellen können, und entscheiden Sie dann, ob Komfort und Wiederherstellungsmöglichkeiten zu Ihrem Alltag passen. Das ist hilfreicher, als eine neue Anmeldetechnik für ein Wundermittel zu halten.
