# Ein Sicherungsplan, auf den Sie sich verlassen können

Eine Sicherung ist nur dann hilfreich, wenn sie die benötigten Dateien enthält und Sie diese bei einem Problem wiederherstellen können. Ein synchronisierter Ordner macht Dateien auf mehreren Geräten verfügbar, kann aber auch ein versehentliches Löschen oder eine unerwünschte Änderung weiterübertragen. Eine separate Sicherung bietet einen zusätzlichen Weg zurück.

Für den Anfang brauchen Sie kein aufwendiges System. Sie brauchen eine klare Liste der wichtigen Dateien, eine getrennt von den Originalen gespeicherte Kopie und die kleine Gewohnheit, deren Funktion zu überprüfen.

## Beginnen Sie mit Dateien, die Ihnen fehlen würden

Denken Sie über den Dokumente-Ordner hinaus. Zu wichtigen Dateien können Familienfotos, persönliche Unterlagen, kreative Projekte, exportierte Notizen und Informationen zur Kontowiederherstellung gehören. Manche Daten liegen bereits bei einem Dienstanbieter; andere gibt es nur auf einem Laptop oder Telefon.

Erstellen Sie eine Übersicht der Speicherorte dieser Dateien. Entscheiden Sie anschließend, welche eine zweite Kopie benötigen und wie oft sie sich ändern. Ein Ordner mit aktiven Arbeitsdateien braucht möglicherweise häufige Sicherungen; ein selten verändertes Archiv muss vielleicht nur gelegentlich aktualisiert werden.

## Bewahren Sie eine unabhängige Kopie auf

Für eine einfache Lösung zu Hause kann eine externe Festplatte oder ein seriöser Cloud-Backup-Dienst eine getrennte Kopie bereitstellen. Entscheidend ist die Trennung: Wenn das Originalgerät verloren, beschädigt oder nicht verfügbar ist, sollte die Sicherung weiterhin erreichbar sein.

Wenn Sie eine externe Festplatte verwenden, schließen Sie sie für die Sicherung an und trennen Sie sie danach wieder. Eine ständig angeschlossene Festplatte kann denselben Verlusten, Unfällen oder Schadprogrammen ausgesetzt sein wie der Computer. Wenn Sie einen Cloud-Anbieter nutzen, informieren Sie sich über Aufbewahrungs- und Wiederherstellungsoptionen. Dateisynchronisierung allein ist nicht unbedingt eine versionierte Sicherung.

Organisationen orientieren sich häufig an der Faustregel „3-2-1“: drei Kopien wichtiger Daten, auf zwei Arten von Speichermedien, davon eine an einem anderen Ort. Das ist eine hilfreiche Denkweise für Ausfallsicherheit, keine Garantie und keine Pflicht für jeden Haushalt, ein großes System anzuschaffen. Beginnen Sie mit einer unabhängigen Kopie und bauen Sie den Schutz bei Bedarf aus.

## Schützen Sie den Zugriff auf die Sicherung

Eine Sicherung kann mehr persönliche Informationen enthalten, als man vermutet. Verwenden Sie ein starkes, einzigartiges Passwort für das Konto oder Gerät, auf dem sie gespeichert ist, und aktivieren Sie die Mehr-Faktor-Authentifizierung, wenn der Anbieter sie unterstützt. Wenn Sie ein Laufwerk verschlüsseln, bewahren Sie den Wiederherstellungsschlüssel separat und sicher auf. Ohne einen wiederherstellbaren Schlüssel kann die Sicherung für Sie unbrauchbar werden.

Bewahren Sie die einzige Kopie eines Wiederherstellungscodes nicht auf demselben Gerät oder in demselben Konto auf, das dieser Code wiederherstellen soll. Überlegen Sie, gegen welchen konkreten Ausfall Sie sich absichern und ob Ihr Plan diesen übersteht.

## Üben Sie die Wiederherstellung einer Datei

Führen Sie einen kleinen Wiederherstellungstest durch. Wählen Sie eine unkritische Datei, holen Sie sie aus der Sicherung zurück und öffnen Sie sie. So stellen Sie fest, ob Sie die Sicherung finden, sich anmelden oder das Laufwerk anschließen und die Wiederherstellungsschritte ausführen können. Wiederholen Sie den Test nach einem größeren Gerätewechsel oder einem Anbieterwechsel.

Prüfen Sie außerdem, ob die Sicherungen erfolgreich abgeschlossen werden. Eine Kalendererinnerung oder eine Benachrichtigung Ihrer Sicherungssoftware kann dabei helfen. Meldet ein Dienst einen Fehler, sollten Sie ihn beheben, statt anzunehmen, dass die nächste Sicherung das Problem von selbst löst.

## Passen Sie den Plan an Ihren Alltag an

Notieren Sie, wo die Sicherung liegt, wie sie geschützt ist und wie Sie eine Datei wiederherstellen. Bewahren Sie diese Notiz so auf, dass sie auch bei einem Ausfall Ihres Hauptgeräts erreichbar ist, und schützen Sie die darin genannten Passwörter und Wiederherstellungsschlüssel.

Der beste Sicherungsplan ist nicht der komplizierteste. Es ist der Plan, den Sie regelmäßig nutzen, auf den Sie an einem schwierigen Tag zugreifen können und den Sie getestet haben, bevor Sie ihn brauchen. Weitere Hinweise zur Vorbereitung enthält der [CISA StopRansomware-Leitfaden](https://www.cisa.gov/stopransomware/ransomware-guide) mit Empfehlungen zum Schutz und zur Wiederherstellung von Daten.
